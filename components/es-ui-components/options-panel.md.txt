An elegant way to display options in an options page, with a contained width and options for label and help text.

<span slot="fallback">Loading interactive example…</span>

```jsx
<OptionsPanel>
	<OptionsPanelSection>
		<span>This is demo content</span>
	</OptionsPanelSection>
</OptionsPanel>
```

For the complete list of props, use your IDE's autocomplete functionality.

## Multiple sections

<span slot="fallback">Loading interactive example…</span>

```jsx
<OptionsPanel>
	<OptionsPanelSection>
		<span>Section 1 content</span>
	</OptionsPanelSection>
	<OptionsPanelSection>
		<span>Section 2 content</span>
	</OptionsPanelSection>
</OptionsPanel>
```

## Title, subtitle, and help text

<span slot="fallback">Loading interactive example…</span>

```jsx {2,3,4}
<OptionsPanel
	title='Demo panel title'
	subtitle='Demo panel subtitle'
	help='Demo panel help'
>
	<OptionsPanelSection>
		<span>Section content</span>
	</OptionsPanelSection>
</OptionsPanel>
```

## Header

To augment the `OptionsPanel`s, you can add an `OptionsPanelHeader` to nicely divide the sections of your options pages.

<span slot="fallback">Loading interactive example…</span>

```jsx
<OptionsPanelHeader title='Global settings' />
```

You can also add `actions` to the right.

<span slot="fallback">Loading interactive example…</span>

```jsx {3}
<OptionsPanelHeader
	title='Global settings'
	actions={<Button icon={save}>Save</Button>}
/>
```

Additional content can be added below the title by passing it as children.

<span slot="fallback">Loading interactive example…</span>

```jsx
<OptionsPanelHeader title='Global settings'>
	// highlight-start Lorem ipsum dolor sit amet. // highlight-end
</OptionsPanelHeader>
```

You can also limit the width of the header using the `limitWidth` prop,
change the heading level of the title with the `level` prop,
or make it sticky with the `sticky` prop.
