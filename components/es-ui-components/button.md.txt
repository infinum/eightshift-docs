## Button groups

If buttons are related, they can be grouped with a `ButtonGroup`.

<span slot="fallback">Loading interactive example…</span>

```jsx {1,5}
<ButtonGroup>
	<Button>First</Button>
	<Button>Second</Button>
	<Button>Third</Button>
</ButtonGroup>
```

Button groups improve focus behavior - instead of having to `Tab` through each button,
the group is treated as a single focusable element that can be navigated with left/right arrows.

### Vertical group

<span slot="fallback">Loading interactive example…</span>

In this case, the focus navigation is handled with up/down arrows.

```jsx {2}
<ButtonGroup
	vertical
>
	<Button>First</Button>
	<Button>Second</Button>
	<Button>Third</Button>
</ButtonGroup>
```

:::note
By default, vertical button groups take up the full width of their container.
:::

### Tooltip

<span slot="fallback">Loading interactive example…</span>

```jsx {3}
<Button
	icon={emptyCircle}
	tooltip="Hi, I'm a tooltip!"
/>
```

:::note
If text label is not set, please set the `aria-label` prop to ensure accessibility.

<br />

When `aria-label` is set, `tooltip` can be just passed without value. In that case it will take the value from
`aria-label`. :::

### Pending

If you want to show a pending state, you can use the `pending` prop.
It will replace the button content with a loading indicator, announce an action, and disable the button.
