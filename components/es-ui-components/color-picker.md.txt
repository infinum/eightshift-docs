## Highlighted props

For the complete list of props, use your IDE's autocomplete functionality.

### Allow deselecting a color

<span slot="fallback">Loading interactive example…</span>

```jsx {5}
<ColorPicker
	value={value}
	onChange={(value) => setData(value)}
	colors={myColors}
	clearable
/>
```

### Disable color grouping

By default, colors are grouped by their names, e.g. `red-100`, `red-200`, `red-300`...

<span slot="fallback">Loading interactive example…</span>

```jsx {5}
<ColorPicker
	value={value}
	onChange={(value) => setData(value)}
	colors={myColors}
	noColorGroups
/>
```

### Show color hex code in the dropdown

<span slot="fallback">Loading interactive example…</span>

```jsx {5}
<ColorPicker
	value={value}
	onChange={(value) => setData(value)}
	colors={myColors}
	showColorCode
/>
```
