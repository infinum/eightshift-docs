This is a versatile component that can allow selecting from a set of options in various ways.

<Example1 client:only="react"><span slot="fallback">Loading interactive example…</span></Example1>

```jsx
<OptionSelect
	icon={columns}
	label='Option'
	value={value} // e.g. 'option1'
	onChange={(value) => setData(value)}
	options={[
		{ value: 'option1', label: 'Option 1' },
		{ value: 'option2', label: 'Option 2' },
		{ value: 'option3', label: 'Option 3' },
	]}
/>
```

#### Submenu

Meant to be used as a part of a `Menu`.

`type='submenu'`

Most item features from `'menu'` are supported.

<Example13 client:only="react"><span slot="fallback">Loading interactive example…</span></Example13>

```jsx
<Menu>
	<MenuItem>Lorem</MenuItem>
	<MenuItem>Ipsum</MenuItem>
	<MenuSeparator />
	<OptionSelect
		label='Option'
		value={data}
		onChange={setData}
		options={[
			{ value: 'option1', label: 'Option 1', icon: design },
			{ value: 'option2', label: 'Option 2', icon: wrench },
			{ value: 'option3', label: 'Option 3', icon: magicAlt },
		]}
		type='submenu'
	/>
</Menu>
```
##### Additional features

If no `label` is provided, the current value will be used as a label.

<Example14 client:only="react"><span slot="fallback">Loading interactive example…</span></Example14>

If `subtitle` is set (to `true`), the current value will be used as a subtitle.

<Example15 client:only="react"><span slot="fallback">Loading interactive example…</span></Example15>
