## Image placeholder

<Example1 client:only="react"><span slot="fallback">Loading interactive example…</span></Example1>

```jsx
<ImagePlaceholder url='https://picsum.photos/200' />
```
### Image display mode

<Example2 client:only="react"><span slot="fallback">Loading interactive example…</span></Example2>

```jsx {3}
<ImagePlaceholder
	url='https://picsum.photos/900/380'
	imageMode='contain'
/>
```
### Sizes

<Example3 client:only="react"><span slot="fallback">Loading interactive example…</span></Example3>

```jsx {3}
<ImagePlaceholder
	url='https://picsum.photos/900/380'
	size='full'
/>
```
### Styles

<Example4 client:only="react"><span slot="fallback">Loading interactive example…</span></Example4>

```jsx {2}
<ImagePlaceholder
	style='simple'
/>
```
### No image (placeholder only)

This can also be achieved by not providing an `url`, but this should be
a bit more performant as you don't have an `<img>` without a source.

<Example5 client:only="react"><span slot="fallback">Loading interactive example…</span></Example5>

```jsx {2}
<ImagePlaceholder
	noImage
/>
```

## Media placeholder

`style` and `size` works the same as in the `ImagePlaceholder`, so they won't be covered again.

<Example7 client:only="react"><span slot="fallback">Loading interactive example…</span></Example7>

```jsx
<MediaPlaceholder icon={magicAlt} />
```
### Help text

<Example8 client:only="react"><span slot="fallback">Loading interactive example…</span></Example8>

```jsx {5}
<MediaPlaceholder
	icon={experiment}
	style='simple'
	size='large'
	helpText='Lorem ipsum dolor.'
/>
```
