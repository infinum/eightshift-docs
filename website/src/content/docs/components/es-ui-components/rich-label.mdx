Upgrade your basic labels with an optional icon and subtitle.

<Example1 client:only="react"><span slot="fallback">Loading interactive example…</span></Example1>

```jsx
<RichLabel
	label='Label ipsum dolor sit amet'
	subtitle='Subtitle ipsum dolor sit amet'
	icon={emptyCircle}
/>
```

### Monochrome

If you have cases where the text might be a different color, or of dynamic color,
use the `noColor` prop to use opacity to highlight hierarchy instead of multiple colors.

<Example3 client:only="react"><span slot="fallback">Loading interactive example…</span></Example3>

```jsx
// The container has a red text color applied.
<RichLabel
	label='Label ipsum dolor sit amet'
	subtitle='Subtitle ipsum dolor sit amet'
	icon={solidCircleFilled}
/>
```
