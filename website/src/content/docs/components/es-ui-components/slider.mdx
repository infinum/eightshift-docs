## Range slider

In order for the value display to be visible, a `label` must be set!

<Example2 client:only="react"><span slot="fallback">Loading interactive example…</span></Example2>

```jsx {3}
<Slider
	label='My slider'
	value={value} // e.g. [20, 60]
	onChange={(value) => setData(value)}
/>
```
