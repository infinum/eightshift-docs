If you need the toggle switch standalone, you can use the `Switch` component.

Other props are the same, with the exception of label and related props.

## Highlighted props

For the complete list of props, use your IDE's autocomplete functionality.

### Icon, subtitle

Augment the label

<Example3 client:only="react"><span slot="fallback">Loading interactive example…</span></Example3>

```jsx {2,3}
<Toggle
	icon={emptyRect}
	subtitle='Subtitle'
	label='Demo'
	checked={data}
	onChange={setData}
/>
```
### Disabled

Prevent interactions with the toggle.

<Example4 client:only="react"><span slot="fallback">Loading interactive example…</span></Example4>

```jsx {5}
<Toggle
	label='Demo'
	checked={data}
	onChange={(value) => setData(value)}
	disabled
/>
```
### Indeterminate state

Whether the toggle should be rendered in an indeterminate state.

<Example5 client:only="react"><span slot="fallback">Loading interactive example…</span></Example5>

```jsx {5}
<Toggle
	label='Demo'
	checked={data}
	onChange={(value) => setData(value)}
	isIndeterminate={data === null}
/>
```
