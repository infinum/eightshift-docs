The `conditionalTags` object contains methods used to manipulate conditional logic.

:::tip
For more details about this feature visit [conditional-tags](/forms/features/conditional-tags) feature.
:::

<Example1 />

### Example

This example will set conditional logic to a field.

```js
window?.esForms?.conditionalTags?.setField('<name>', '<formId>');
```
